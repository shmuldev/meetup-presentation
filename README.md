# Meetup presentation

Open `index.html` in a browser. All fonts and QR codes are embedded; no internet required to present.

- Arrow keys / Space / Page Down: next slide
- Left arrow / Page Up: previous slide
- Home / End: first / last slide
- F: fullscreen
- Scroll or swipe to navigate; hover at the bottom for slide buttons

Five slides: community QR opening, then four debate topics with participants.
